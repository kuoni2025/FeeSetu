# FeeSetu V15.1

## Admin authentication
- Admin login screen added.
- Default username: `admin`
- Default password: `FeeSetu@2026`
- Admin dashboard is hidden until successful login.
- Logout clears the browser session.
- Institution name, address and UPI ID can be saved from Admin.
- The credentials are intentionally not exposed in the public kiosk UI.

## Note
This is an authentication layer for the current V15 scaffold. For production deployment, move authentication and credentials to server-side environment variables/database, use HTTPS, password hashing, CSRF/session protection and a real payment gateway server-side verification flow.
