# FeeSetu Kiosk V3

This build replaces the previous kiosk layout with a true phone-style 3-column keypad.

Key design:
- No large title or progress stepper on the search screen.
- Large input, three compact search modes, then keypad.
- Enrollment/Roll use multi-tap alphanumeric keys.
- Mobile uses numeric-only keys.
- 0 key cycles `0 -> / -> -` for Enrollment/Roll so the visible keypad stays 3x4.
- Clear and Backspace are separate.
- Search is one full-width primary action.
- Responsive sizing for desktop, short desktop, tablet and mobile.
