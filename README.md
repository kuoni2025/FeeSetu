# FeeSetu V16 Local Professional

## Run locally
1. Install Node.js 18+.
2. Double-click `RUN_LOCAL.bat`.
3. Open http://127.0.0.1:3000

Admin: `admin` / `feesetu`

## Excel columns
Enrollment, Roll, Mobile, Name, Father, Course, Session, Semester, Photo

This is a local functional prototype. Data is stored in `data/*.json`.
