# FeeSetu Clean UI / Branding Asset Pack

Version: V1 Clean Generic

यह पैकेज संस्था-विशिष्ट branding से अलग रखा गया है। किसी भी PNG में किसी कॉलेज/संस्था का वास्तविक नाम, पता या वास्तविक संस्था-लोगो embed नहीं किया गया है।

## User-configurable branding
- संस्था का नाम
- संस्था का पता
- संस्था का लोगो
- संपर्क/फोन
- वैकल्पिक tagline

इन चीजों को software के Admin/Settings में upload/configure करके UI और receipt में लगाया जाना चाहिए।

## Asset folders
- backgrounds: kiosk/login background
- branding: FeeSetu brand + replaceable logo slot
- icons: search modes and actions
- buttons: reusable button visuals
- keyboard: keyboard key visual references
- status: payment/status indicators
- profile: photo/no-photo placeholders
- receipt: generic receipt header
- badges: status badges
- tables: table header
- decorative: optional background motifs

## महत्वपूर्ण
Functional keyboard buttons HTML/CSS में बनाए जाएँ; PNG keyboard assets केवल visual reference/background नहीं बल्कि button styling reference हैं। संस्था-specific images को hard-code न करें।
