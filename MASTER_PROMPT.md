# FeeSetu — Master Build Prompt

Build FeeSetu as a professional, responsive student fee-payment kiosk and admin system. Use the supplied UI Asset Pack in `public/assets` as the visual source of truth wherever appropriate. Do not hard-code institution name, address or institutional logo into generic assets. Institution branding must be configurable from Admin Settings and must appear dynamically in kiosk/header and receipt.

## Non-negotiable UX
- Student identification is fixed and separate: Enrollment Number searches only enrollment; Roll Number searches only roll; Mobile Number searches only mobile.
- Student login/selection and the on-screen keyboard are separate pages.
- Enrollment and Roll use a real functional alphanumeric keyboard. Mobile uses numeric keyboard only.
- No multi-tap keyboard.
- Kiosk touch targets must be large, aligned and responsive.
- Receipt must generate and print.
- Admin must provide institution settings, Excel import, student-data deletion, payment-record viewing and receipt opening.
- Responsive for kiosk, desktop, laptop, iPad and Android/iOS tablets/mobile.
- Preserve clean saffron/white/navy visual language; do not overcrowd the screen.
- Use assets as assets, not merely as unused files.
